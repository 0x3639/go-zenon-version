Zenon Observatory

Explore observed Zenon peers, compare go-zenon node versions, identify seed nodes, and inspect direct P2P handshake results.

This is a partial view of the network. Peer identities, public IP addresses, and registered pillars are separate counts. Versions are self-reported; a failed inbound connection does not prove a node is offline.

The interactive dashboard loads with JavaScript. The guide and public API are also available directly.
